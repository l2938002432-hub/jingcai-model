# 多联赛样本外基线（2026-07-22）

对每个联赛按时间排序取最近 500 场，前 250 场训练、后 250 场逐场扩展训练集预测；只比较胜平负概率，不使用未来信息。

| 联赛 | Log Loss 改善 | Brier 改善 | 状态 |
|---|---:|---:|---|
| 挪超（NOR） | 4.34% | 5.04% | PAPER_ONLY 通过 |
| 巴甲（BRA） | 1.30% | 2.35% | PAPER_ONLY 通过 |
| 美职（USA） | 0.29% | 0.57% | 未通过，停止候选 |

通过线暂定为 Log Loss 与 Brier 相对历史频率基线均改善至少 1%。这不是盈利验收：由于没有可信、带时间戳的历史中国竞彩固定奖金，ROI 仍不可计算。欧冠资格赛尚未补齐同口径历史，因此停止候选。

后续数据完整性审计发现 USA 历史记录存在日/月混排，例如真实 2024-03-02 的比赛被写成 2024-02-03。由于这可能改变时间训练顺序，此前 MLS 的 0.86%/1.03% 复核结果现已作废，不得作为准入依据。系统将使用独立 OpenFootball MLS 赛程按赛季、主客队和 90 分钟比分唯一交叉校正，无法唯一确认的记录隔离，再建立从未参与调参的新锁箱。欧战新增 OpenFootball CC0 资格赛解析，能严格提取 90 分钟比分并覆盖 Kairat、Omonia，但当前可靠同口径样本仍不足以完成独立验收。

交叉校正实际覆盖 5,233 场中的 5,067 场（96.8%），166 场因无唯一匹配被隔离。冻结的现有 Dixon-Coles 模型在修复后最新 250 场上的 Log Loss 改善为 -0.057%，Brier 改善为 0.005%，没有通过双 1% 门槛，MLS 继续保持未批准。该结果可由 `scripts/validate_mls_integrity.py` 重现；后续只能在更早开发集选择时间衰减或集成参数，不得用这 250 场反复调参。

时间衰减 Dixon-Coles 仅在锁箱之前的 250 场开发窗口比较预先声明的 180/365/540 天半衰期。三者 Log Loss 改善分别为 -0.659%/-0.684%/-0.600%，Brier 改善分别为 -0.619%/-0.717%/-0.638%，全部劣于基准，因此未选择任何候选，也没有再次打开最新锁箱。负结果被保留，防止为了准入而继续试参。
