# 英超六赛季概率基线验收

## 目的

验证基础 Dixon–Coles 模型是否能在严格时间外数据上学习到比“历史主胜/平/客胜频率”更有效的概率规律。本验收不使用中国竞彩历史固定奖金，因此不得计算或宣称竞彩 ROI。

## 协议

- 按开赛时间排序。
- 前 760 场作为首个训练窗口。
- 后续 1,520 场逐场预测，每次仅使用该场之前的比赛重新拟合。
- 候选模型：时间更新的 Dixon–Coles 比分模型。
- 基线：截至预测时点的平滑历史主胜/平/客胜频率。
- 指标：多分类 Log Loss 与 Brier；越低越好。

## 结果

| 指标 | Dixon–Coles | 历史频率基线 | 相对改善 |
|---|---:|---:|---:|
| Log Loss | 1.0037045682 | 1.0701234126 | 6.2% |
| Brier | 0.5992459152 | 0.6475081155 | 7.5% |

`roi_status` 为 `UNAVAILABLE_WITHOUT_TRUSTED_SPORTTERY_ODDS`，符合禁止使用非官方奖金宣称竞彩收益的设计门槛。

## 结论与限制

基础模型在该时间外样本上明显优于简单历史频率，证明历史训练具备概率预测价值。该结论仍不足以证明可盈利：下一步必须加入同一预测时点的市场去水概率基线、校准置信区间、更多联赛和可信中国竞彩历史奖金快照。
